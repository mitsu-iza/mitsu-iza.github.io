# 仙台製造所 本数計管理システム - 作業者マスタ

このプロジェクトは、添付画像に基づいて作成された仙台製造所の本数計管理システムの作業者マスタ画面です。

## 機能

- **作業者データ表示**: 作業者番号、名前1、名前2の一覧表示
- **データ登録**: 新しい作業者情報の登録
- **データ削除**: 選択した作業者情報の削除
- **行選択**: テーブル行をクリックして作業者情報を選択
- **メッセージ表示**: 操作結果のメッセージ表示
- **下部メニュー**: 検索・一覧、作業者、パラメータ、サーバー管理ボタン

## 技術スタック

- **Framework**: ASP.NET Core 8.0 MVC
- **Language**: C#
- **Frontend**: HTML, CSS, JavaScript
- **Development Environment**: .NET SDK 8.0

## 起動方法

1. プロジェクトディレクトリに移動:
   ```bash
   cd SeizoManagementSystem
   ```

2. アプリケーションを起動:
   ```bash
   dotnet run
   ```

3. ブラウザで以下のURLにアクセス:
   ```
   http://localhost:5000
   ```

## 画面操作

### 作業者登録
1. 右側の入力フォームに作業者情報を入力
2. 「登録」ボタンをクリック
3. 登録完了メッセージが表示され、テーブルに新しいデータが追加されます

### 作業者削除
1. テーブルから削除したい作業者の行をクリック
2. 「削除」ボタンをクリック
3. 確認ダイアログで「OK」をクリック
4. 削除完了メッセージが表示され、テーブルからデータが削除されます

### 行選択
- テーブルの行をクリックすると、その行が選択状態になり、右側の入力フォームに値が自動入力されます

## 初期データ

システム起動時には以下の初期データが登録されています:
- 作業者番号: 001
- 名前1: JFE
- 名前2: タロウ

## カスタマイズ

### スタイル変更
`Views/WorkerMaster/Index.cshtml`のCSSセクションでデザインをカスタマイズできます。

### データ永続化
現在はメモリ内でデータを管理していますが、データベース連携を追加することで永続化が可能です。
